# 9. Major SQL Filtering Bug (Critical Debugging)

## Symptoms

* SQL showed 12 drones
* React showed only 7
* No visible errors

---

## Root Cause

Backend query used:

```sql
(? IS NULL OR field = ?)
```

But controller passed:

```js
""
```

instead of:

```js
null
```

---

## Problem Example

This became:

```sql
("" IS NULL OR field = "")
```

Which incorrectly filtered rows.

---

## Fix Applied

Changed:

```js
country || ""
```

to:

```js
country || null
```

---

## Result

Correct filtering:

* India → 12 drones displayed
* Germany → correct results
* Empty filters → all rows returned

# 7. Major Backend Debugging & Fixes

## 7.1 Error — `items.map is not a function`

### Cause

Frontend expected arrays but backend occasionally returned non-array structures.

### Fix

Frontend normalization was added:

```js
if (data && typeof data === "object") {
  setResults(data);
}
```

And rendering logic was protected using:

```js
Array.isArray(items)
```

---

## 7.2 Error — Empty Global Search Results

### Symptoms

Queries like:

* MQ-9
* India
* LiPo

returned no visible results.

---

### Root Causes Identified

#### Problem 1 — Wrong Database Table

Query attempted:

```sql
FROM drones
```

But actual schema contained:

* `drone_platforms`
* `drone_variants`

### Error

```txt
ER_NO_SUCH_TABLE
Table 'drone_forensics.drones' doesn't exist
```

### Fix

Global search SQL was rewritten using joins:

```sql
FROM drone_platforms dp
JOIN drone_variants dv
LEFT JOIN countries c
```

---

#### Problem 2 — Wrong Column Name

### Error

```txt
Unknown column 'dp.role_primary'
```

### Cause

`role_primary` exists in `drone_variants`, not `drone_platforms`.

### Fix

Changed:

```sql
dp.role_primary
```

to:

```sql
dv.role_primary
```

---

Global search was improved to support:

* Countries
* Platform names
